# Beispielseiten für in48stunden

Hier liegen fertige Beispielseiten mit vollem Quelltext. Wer überlegt, eine Seite bauen zu lassen,
kann vorher hineinsehen: einfache, lesbare Dateien statt Baukasten.

Geplant sind drei Beispiele für erfundene Betriebe: Handwerk, Praxis, Coaching.

Angebot: https://in48stunden.de

## Selbst bauen

```sh
npm install
npm run build   # Seiten nach dist/
bin/gewicht     # baut und misst je Seite, scheitert über 500 KB
```
